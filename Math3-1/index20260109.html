    • (A) x+(x−5)=3x + (x - 5) = 3x+(x−5)=3
    • (B) x+(x+5)=3x + (x + 5) = 3x+(x+5)=3
    • (C) x+(x−5)=300x + (x - 5) = 300x+(x−5)=300
    • (D) x+(x+5)=300x + (x + 5) = 300x+(x+5)=300
    • 解答：(C)
    • 計算過程：
      • 注意單位一致性：3 m=300 cm3\text{ m} = 300\text{ cm}3 m=300 cm。
      • 較長一段為 x cmx\text{ cm}x cm，則較短一段為 (x−5) cm(x - 5)\text{ cm}(x−5) cm。
      • 兩段長度相加等於總長：x+(x−5)=300x + (x - 5) = 300x+(x−5)=300。
  1. 題目內容：一元及五元的硬幣共 202020 個，合計 929292 元，則五元硬幣有幾個？

      • 設五元硬幣有 xxx 個，則一元硬幣有 (20−x)(20 - x)(20−x) 個。

      • 最大的數為 x+1=5+1=6x + 1 = 5 + 1 = 6x+1=5+1=6。
